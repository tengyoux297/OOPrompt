# Extension Icons

This directory should contain the following icon files for the Chrome extension:

- `icon-16.png` - 16x16 pixels (toolbar icon)
- `icon-48.png` - 48x48 pixels (extension management page)
- `icon-128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

You can create these icons using any image editor. Recommended tools:
- Figma
- Adobe Illustrator
- GIMP
- Online tools like https://www.favicon-generator.org/

The icons should represent the OOPrompt logo/brand. Make sure they are:
- Square (same width and height)
- PNG format
- Clear and recognizable at small sizes
- Consistent design across all sizes

## Temporary Placeholder

Until proper icons are created, you can use any 16x16, 48x48, and 128x128 PNG images as placeholders for testing.
